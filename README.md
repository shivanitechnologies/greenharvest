# greenharvest

Organic Grocery & Natural Foods Store — Responsive e-commerce web platform and Stackly template project.

## 🌿 Overview
**GreenHarvest** (Brand: *Pokusa for Health*, Concept: *Organic Harvest*, Tagline: *Fresh From Nature · Organic food · Natural products · Healthy living*) is a modern, responsive web application for a premium organic grocery and natural food store.

## 🎨 Brand Identity
- **Primary Color:** `#315C3B` (Forest Green)
- **Secondary Color:** `#D6A85F` (Harvest Gold)
- **Light Theme Surface:** `#FBF9F5` / `#F4EFEA`
- **Dark Theme Surface:** `#121614` / `#1A211D`
- **Typography:** Poppins (Headings) + Inter (Body Text)

## 📁 Key Pages & Structure
### Public Storefront
- `index.html` — Classic Organic Store with Live Harvest Telemetry, Custom Box Configurator, Soil Impact Dashboard, and Seasonal Radar.
- `home-2.html` — Editorial Organic Experience with farm photography, lifestyle stories, and recipe pairings.
- `about.html` — Our Story, milestones, sustainable farming practices, and certifications.
- `products.html` — Full catalog with category filtering, live price slider, sort controls, and mobile pill scroller.
- `product-details.html` — Multi-angle gallery, interactive weight selectors (250g, 500g, 1kg), delivery PIN checker, and mobile sticky purchase bar.
- `why-organic.html` — Educational guide with organic vs conventional comparative tables.
- `delivery-info.html` — Cold-chain shipping process, PIN code serviceability tester, and refund policies.
- `contact.html` — Inquiry form with live validation and store depot map.
- `pricing.html` — Harvest Club membership subscription plans.
- `cart.html` — Shopping cart with voucher discounts and delivery calculation.
- `checkout.html` — Secure checkout flow with address validation and payment options.
- `order-success.html` — Order confirmation invoice with live order stage tracker.
- `wishlist.html` — Saved favorite products grid.

### Administration Portal (`/admin`)
- `admin/dashboard.html` — Real-time metrics, revenue charts, and transaction feeds.
- `admin/products.html` — Product catalog management and stock switches.
- `admin/categories.html` — Category management.
- `admin/orders.html` — Order fulfillment and status workflows.
- `admin/customers.html` — Customer profiles and purchase histories.
- `admin/inventory.html` — Stock thresholds and quick restock tools.
- `admin/messages.html` — Customer inquiries inbox and response modals.
- `admin/delivery-management.html` — Serviceable PIN codes and delivery zone controls.
- `admin/reports.html` — Performance reports and CSV export.
- `admin/settings.html` — Store configuration and logistics policies.

### Authentication & Utilities
- `login.html`, `register.html`, `forgot-password.html`
- `404.html`, `coming-soon.html`, `maintenance.html`

## 🛠️ Tech Stack
- HTML5, Tailwind CSS
- Vanilla JavaScript (Modular ES6 architecture)
- LocalStorage persistence for Cart, Wishlist, Orders, Messages, and Theme preferences
- Full Dark Mode & RTL Support
